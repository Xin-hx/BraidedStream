你正在维护一个 D3 + TypeScript 的 Braided StreamGraph 研究型 demo。现在要进行一次“研究原型级”升级，而不是仅做界面美化。请按以下 PRD 完成设计与实现。

====================
一、产品目标
====================

将当前 demo 从“参数调节器”升级为“方法研究原型”：

1. 主图（main view）保持原始 streamgraph，不在 ROI 内直接显示 braided deformation。
2. ROI 仅作为“分析窗口 / 放大窗口”的选择器。
3. 在单独的 inset 子图（局部放大图）中展示 ROI 对应的局部时间窗口，并在该子图内：
   - 使用 braided 布局
   - 展示更细尺度特征
   - 展示 uncertainty / gap / diff / ruler 等局部分析信息
4. 这种“主图 + 子图局部放大”的形式，参考地理学中的 inset map / local zoom figure：
   - 主图给出全局上下文
   - 子图给出局部增强表达
   - 两者之间有明确对应关系
5. 整个系统要同时支持：
   - 交互分析
   - 静态导出（适合论文图/海报图）

研究定位：
- 主图负责 global context
- inset 子图负责 local explanation
- braided 不再直接破坏主图连续性，而成为一种局部增强表达
- 这将成为方法的“形式创新点”之一

====================
二、核心设计原则
====================

必须遵守以下原则：

P1. 主数值映射不变
- 原始 mean thickness 语义不能被破坏
- braided 只能在 inset 中使用
- 主图中 ROI 区域不得直接改写层厚度/边界

P2. 主图不直接 braided
- main chart 始终展示 base streamgraph（根据 baseline 计算）
- ROI 在主图中仅用半透明刷选框 + 边界高亮显示
- 主图可以显示 ROI 边界或 leader lines，但不能直接出现 braided 裂缝

P3. inset 子图是“局部增强视图”
- inset 只展示 ROI 的时间范围
- inset x 方向放大，必要时 y 方向也可独立放大
- inset 内允许显示 braided、uncertainty band、diff、ruler、gap semantics 等
- inset 必须能够独立阅读

P4. 适合静态载体
- 即使禁用交互，导出的图仍然应当清晰表达：
  主图中的选区 -> 对应到 inset 子图 -> inset 中的增强表达
- 因此必须有明显的视觉连接机制

====================
四、第一优先级：研究有效性（必须完成）
====================

--------------------------------
A. 指标面板（before / after）
--------------------------------

新增一个 metrics panel，至少包含以下指标：

A1. Readability / geometry
- Mean slope in ROI
- Max slope in ROI
- Wiggle energy
- Sine-illusion proxy
- Mean layer separation
- Min layer separation

A2. Cost / fidelity
- Extra space used
- Compactness loss
- ROI boundary distortion
- Thickness invariance error
- Order stability

A3. 展示形式
每个指标用表格形式展示：
- Before
- After
- Delta
并支持高亮显示“改善/恶化”。

A4. 作用范围
- 默认只统计 ROI 时间窗口
- 可切换显示 global vs ROI-local

--------------------------------
B. Before / After / Diff 对照
--------------------------------

在 inset 子图中增加 view mode 切换：

- before：原始局部 streamgraph
- after：braided 局部视图
- diff：只显示变化量/新增 gap/边界位移
- split：上下或左右并排显示 before 与 after

要求：
- diff 视图不能只是简单重画，要明确编码“变化在哪里”
- 建议用以下任一方式：
  1) 轮廓偏移阴影
  2) gap 区域着色
  3) before/after 双轮廓叠加

--------------------------------
C. gap 语义显式化
--------------------------------

当前 gap 不能继续表现为空白裂缝。必须让 gap 成为“结构化语义区域”。

在 inset 中，gap 至少支持 1 种默认语义表达，建议支持多种可切换：

- uncertainty band in gap
- hatch / texture in gap
- mini ruler / local reference marks in gap
- local heat strip representing uncertainty strength

要求：
- gap 不得被读成“数据断裂”
- 必须有 legend 或 label 解释 gap 的含义
- renderMode 需扩展为：
  - meanOnly
  - mean+gapSemantic
  - mean+uncBand
  - diffOnly

--------------------------------
D. 长时间序列 overview + sliding ROI
--------------------------------

新增 overview timeline 组件，实现：

D1. ROI 交互
- brush 选择 ROI
- 拖动整个 ROI 窗口
- 单独拖动左/右边界改变窗口宽度

D2. ROI 同步
- 主图高亮该窗口
- inset 自动刷新为该窗口局部视图
- metrics panel 自动刷新该窗口指标

D3. 建议实现
- ROI 不是单次静态框选，而是长期可滑动分析窗口
- 对长时间序列数据（如 covid）必须保持流畅交互

====================
七、Inset 形式创新：详细要求
====================

这是本次 PRD 的核心创新点，必须重点实现。

--------------------------------
K. 主图 + inset 的视觉连接
--------------------------------

主图与 inset 之间必须有明确的对应关系。支持以下之一或组合：

- connector lines（类似地理 inset map）
- ROI outline -> inset frame 对应
- matching color border
- small label tag，如 “ROI A”

要求：
- 静态导出时仍清晰可见
- 不依赖 hover 才能理解

--------------------------------
L. inset 内容要求
--------------------------------

inset 子图中必须能够表达“更细尺度特征”，具体要求：

L1. x 放大
- 只显示 ROI 时间范围
- 相比主图至少有明显更高的横向分辨率

L2. y 视图增强
- 可独立 y-scale
- 允许更清楚地显示薄层与细小 gap

L3. braid only in inset
- braided deformation 只在 inset 内启用
- main chart 永远显示原始形态

L4. inset 标题与说明
- inset 顶部显示局部视图标题
- 若使用 smoothing / uncertainty proxy，需要在 inset 附近注明

--------------------------------
M. 静态载体友好模式
--------------------------------

新增 static mode / publication mode：

在该模式下：
- 禁止复杂 hover-only 信息
- 强化 connector、legend、ROI outline
- 默认显示 before/after/diff 中最适合静态阅读的一种
- 支持导出 publication-ready figure

====================
八、实现约束与不变量
====================

必须保留以下不变量：

1. 主图 base thickness invariant
- 主图中 layer thickness = original mean
- 主图不能因 ROI 产生 braided deformation

2. inset after-view thickness invariant
- braided 只改变 gap / spacing
- 不得改变 mean thickness

3. ROI outside equivalence
- inset 只处理 ROI 内数据
- 主图其他区域不受影响

4. no overlap
- inset braided 后层之间不能重叠

5. explainability
- gap、diff、metric 含义必须有明确文本或 legend
